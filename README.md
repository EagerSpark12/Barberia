# Barberia - El Corte Fino

Proyecto creado para demostrar mis habilidades como desarrollador frontend a proximos compradores o reclutadores.

Tecnologias usadas:

-Html5
-CSS3
-Flexbox
-CSS Grid
-Responsive Design
-Git y Github
-Variables CSS
-Animaciones y transiciones

Caractereisticas:

-Diseño completamente responsive.
-Navbar adaptable con menú hamburguesa.
-Hero con imagen de fondo y overlay.
-Tarjetas de servicios.
-Galería interactiva con efectos hover.
-Formulario de contacto.
-Footer con enlaces a redes sociales.

Objetivo:

Simular una pagina web para una barbereia moderna, ofreciendo una interfaz interactiva, adatpable a cualquier dispositivo y eenfocada en facilitar el contacto entre el cliente y el negocio.
